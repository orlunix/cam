CAM Desktop — Support

CAM Desktop is a control surface for AI coding agents: it connects to your own machines over SSH and lets you start, watch, and attach to agent sessions from one window.

Get help

  • Report an issue on GitHub
  • Downloads and release notes
  • Privacy policy

Requirements

  • A machine you control with SSH access (Linux/macOS, tmux, Python 3.6+)
  • One or more supported agent CLIs installed on that machine
